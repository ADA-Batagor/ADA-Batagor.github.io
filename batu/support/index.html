Batu Support

iPhone, iPad and Mac

Batu lets you set aside storage as a reserve, then release it at any time to free up space instantly. The reserve is a placeholder file inside the app, so releasing it simply deletes that file.

How do I reserve storage?

Open Batu, choose how much storage to set aside, and confirm. Batu creates the reserve file inside its own container.

How do I release it?

Open Batu and release the reserve. The file is deleted and the space becomes available again.

I released the reserve, but my free space didn't go up right away. Why?

Some of the space may be held by APFS snapshots, such as Time Machine local snapshots on a Mac. The space is freed once those snapshots are removed, which the system usually does on its own.

Where is the reserve stored?

It's a single file inside Batu's own container. It is deleted when you release the reserve, and also when you delete the app. Batu never touches your photos or other files. See the Privacy Policy.
